# SignatureSystems

WebSocket server for terminal response system with dynamic push updates.

## Server Status
✅ **Server is running on port 3000**

## Connection Details
- **WebSocket Endpoint**: `ws://localhost:3000`
- **Admin Token**: `admin-token-12345`

## Usage

1. The server is already running in the background
2. Connect from the admin interface at signaturebrain.com/admin/:
   - Paste the admin token: `admin-token-12345`
   - Click "Connect"
3. The server will send terminal responses every 1 second

## Commands
```bash
npm start          # Start the server
npm install        # Install dependencies
```
